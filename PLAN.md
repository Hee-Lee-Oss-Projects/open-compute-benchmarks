## Summary

Open, verified benchmark specifications and reference results for common numeric/HPC kernels, so developers can compare implementations fairly and reproducibly.

## Scope

In scope: benchmark definitions, methodology, and reference results for well-known kernels. Out of scope: vendor-specific tuning or closed hardware claims.

## Risk

Low: built on openly-licensed sources with recorded provenance; educational/derivative in nature, no personal data, and no farm-/case-specific prescriptive advice. Each deliverable must cite sources and stay within established, verifiable material.

## Approach

Each task defines one benchmark: inputs, methodology, how to run it, and a reference result, in a reproducible spec.

## Definition of shipped

A set of documented, reproducible benchmark specs with reference results, published openly and runnable by a third party.
